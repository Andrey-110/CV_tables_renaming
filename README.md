Детекция информационных табличек на фотографиях, 
распознавание текста на них,
переименование файлов согласно распознанному тексту.

Используется roboflow, ultralytics и doctr.

Добавлен образец результата и скриншот работы программы, созданной в PyCharm.

Публичный jupyter‑файл представляет собой версию реального файла с исключённой конфиденциальной информацией.
